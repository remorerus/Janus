# RE:Vision SSH Agent

Отдельное Windows-приложение для настройки каталога SSH-команд STUDIO PC. Это **не Windows-служба** и не фоновый агент: программа запускается вручную из меню Пуск, сохраняет команды и полностью закрывается.

## Что умеет

- Создавать, редактировать и удалять пользовательские команды.
- Задавать точную голосовую фразу для каждой команды.
- Выбирать PowerShell или CMD.
- Хранить многострочные команды и сценарии.
- Сохранять каталог в `%ProgramData%\REVisionSshAgent\commands.json`.

## Как выполняется голосовая команда

1. RE:Vision на Android получает голосовую фразу.
2. Android подключается напрямую к STUDIO по SSH с ключом из Android Keystore.
3. SSH запускает `C:\Program Files\RE:Vision SSH Agent\run-ssh-command.ps1`.
4. Runner находит точное совпадение фразы в локальном каталоге и исполняет сохранённую команду от имени SSH-пользователя.
5. Процесс завершается. Отдельный сервер или постоянно работающий процесс RE:Vision SSH Agent не нужен.

Для этого на STUDIO должен работать штатный OpenSSH Server Windows, а публичный ключ RE:Vision должен быть добавлен в `authorized_keys` того же Windows-пользователя, под которым выполняется SSH-вход. Само приложение SSH Agent и его интерфейс не требуется держать открытыми.

## Установка

Распакуй архив, открой PowerShell от имени администратора и запусти `install-ssh-agent.ps1`. Ярлык появится в меню Пуск. Установщик не создаёт службу, задачу планировщика, сетевой слушатель или правило брандмауэра.

Запусти **RE:Vision SSH Agent**, добавь название, точную фразу, оболочку и команду, затем нажми «Сохранить команду». После сохранения приложение можно закрыть.

## Безопасность

Каталог команд содержит исполняемый код. Команды выполняются с правами SSH-пользователя Windows. Добавляй только доверенные команды и защищай доступ к Windows-учётной записи и SSH-ключу.
