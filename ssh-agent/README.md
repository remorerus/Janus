# RE:Vision SSH Agent

Отдельное Windows-приложение с собственным окном. Не является вкладкой или службой Windows Agent и не требует запущенного Windows Agent.

## Возможности оболочки выполнения

Для каждой команды задаётся точная голосовая фраза и один из типов действия:

- **Сценарий PowerShell / CMD** — многострочный сценарий, поддержка параметров и последовательностей команд.
- **Запустить приложение** — полный путь к EXE, аргументы запуска и рабочая папка.
- **Закрыть приложение** — имя процесса без расширения .exe.
- **Перезапустить приложение** — закрывает указанный процесс и запускает EXE заново с заданными аргументами и рабочей папкой.

Команды можно добавлять, редактировать и удалять. Каталог хранится отдельно от Windows Agent:

`%ProgramData%\REVisionSshAgent\commands.json`

Старые записи без поля Action продолжают трактоваться как сценарии PowerShell/CMD.

## Установка

Распакуй архив, запусти `install-ssh-agent.ps1` от имени администратора. Установщик помещает приложение и runner в:

`C:\Program Files\REVision SSH Agent`

Создаётся ярлык «RE-Vision SSH Agent» в меню «Пуск». Приложение запускается пользователем вручную; Windows-служба, планировщик, фоновый listener или tray-процесс не создаются.

## Голосовое выполнение

Android-клиент RE:Vision подключается к Windows OpenSSH Server по ключу (приватный ключ хранится в Android Keystore), передаёт фразу в runner, который находит точное совпадение в каталоге и выполняет выбранное действие от имени SSH-пользователя Windows. Парольная SSH-аутентификация не используется.

Публичный ключ RE:Vision должен находиться в `authorized_keys` той же Windows-учётной записи, от имени которой запускается SSH-сессия. Команды PowerShell/CMD и действия с приложениями выполняются с правами этой учётной записи. Добавляй только доверенные сценарии и исполняемые файлы.
